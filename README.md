# Iro Solonaki portfolio

## Run locally

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

The production site is generated in `dist/` (included in this archive).

## Media update



Dependencies and Git history are excluded from the ZIP; install dependencies with `npm ci`.

Echoes of Time and FLUX: English summaries and four additional screenshots per game are adapted from ITC4445 - GAMES PORTFOLIO.docx. Original gameplay previews remain in the galleries. Descriptions summarize the documented game systems without claiming original authorship of third-party art assets.

Professional work is available on request. Confidential assets and the former client-side access code are excluded from the public source and build.
